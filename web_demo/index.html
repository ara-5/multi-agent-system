Four attempts, same task — reward improved on all of them, but mutual information tells the real story. A single shared network over both agents' concatenated observations reached only 0.9% of max mutual information (200k steps), then 13.5% with 5x the training and an entropy bonus (1M steps) — because that architecture never has to route information through the message: the same network that outputs the listener's move can just read the speaker's target directly. Splitting the policy into two independent sub-networks — message logits computed only from the speaker's observation, movement logits only from the listener's — jumped to 55.3% immediately, but settled for a protocol using only 2 of 3 messages (distinguishing one target from the other two, not those two from each other) — and did so consistently across 3 random seeds (55.3%, 59.5%, 59.5%). Adding a small entropy bonus on top of that architecture reached the model shown here: … of the theoretical maximum — a clean, deterministic one-message-per-target protocol. But rerunning that condition across the same 3 seeds gave 99.7%, 0.0%, and 55.3% — the 0.0% run is a complete collapse (same message every episode, regardless of target). The entropy bonus is a high-variance gamble, not a reliable fix; the model above is the best of three, not the typical outcome. The confusion matrix is measured over 300 held-out episodes. A rising reward curve is evidence the policy improved — only the mutual-information measurement (and, it turns out, rerunning it with more seeds) shows whether that improvement was the thing being tested for, reliably.
